Privacy Policy

Last updated: November 16, 2026

Purpose

PlexStack Backups is a privately operated utility for backing up and restoring application data using Google Drive.

Google Drive Access

The application uses Google Drive API authorization to create, read, update, and delete files required for encrypted backup storage and restoration.

Data Storage and Security

Backup contents are encrypted locally using Restic before being uploaded to Google Drive. OAuth credentials are stored locally on the operator's device.

Data Sharing

The application does not sell user data or intentionally share Google Drive data with advertisers or third parties. Google Drive acts as the authorized storage provider.

Data Retention

Encrypted backup files are retained according to the operator's configured backup retention policy. The operator may delete backups or revoke Google Drive access at any time.

Contact

For privacy or access questions, contact the application operator using the support email displayed on the Google OAuth consent screen.
