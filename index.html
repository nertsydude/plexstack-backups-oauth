PlexStack Backups

Private, encrypted infrastructure backups.

About

PlexStack Backups is a privately operated backup utility used to store and restore encrypted application configuration, metadata, and database backups.

The utility uses Restic and Rclone to securely transfer encrypted backup data to Google Drive.

Access

This application is intended for use by its operator only. It is not a public backup service and does not offer public account registration.
